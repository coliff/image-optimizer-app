# DESCRIPTION

## ENGLISH

- Seven formats: AVIF, GIF, JPEG, JPEG XL, PNG, SVG and WebP.
- Uses the best open source tools under the hood: oxipng, libjpeg-turbo, Gifsicle, libwebp, libavif, libjxl and SVGO (SVGO runs in a built-in JavaScript engine, so no Node.js is needed).
- File Explorer integration. Selecting many files at once opens them all in one window.
- Nothing to configure. The defaults are safe, and a small Settings panel is there if you want it (including a much slower maximum compression mode).
- Keeps each file's original "Date modified" by default.
- Follows the Windows light or dark mode automatically, and uses your High Contrast colors when a contrast theme is on.
- Available in English, French, German, Italian, Japanese and Spanish.

## FRENCH

- Sept formats : AVIF, GIF, JPEG, JPEG XL, PNG, SVG et WebP.
- Utilise les meilleurs outils open source en coulisses : oxipng, libjpeg-turbo, Gifsicle, libwebp, libavif, libjxl et SVGO (SVGO s'exécute dans un moteur JavaScript intégré, Node.js n'est donc pas nécessaire).
- Intégration à l'Explorateur de fichiers. Sélectionner plusieurs fichiers à la fois les ouvre tous dans une seule fenêtre.
- Rien à configurer. Les valeurs par défaut sont sûres, et un petit panneau Paramètres est là si vous le souhaitez (y compris un mode de compression maximale, beaucoup plus lent).
- Conserve par défaut la date « Modifié le » d'origine de chaque fichier.
- Suit automatiquement le mode clair ou sombre de Windows, et utilise vos couleurs de contraste élevé lorsqu'un thème de contraste est activé.
- Disponible en anglais, français, allemand, italien, japonais et espagnol.

## GERMAN

- Sieben Formate: AVIF, GIF, JPEG, JPEG XL, PNG, SVG und WebP.
- Nutzt unter der Haube die besten Open-Source-Tools: oxipng, libjpeg-turbo, Gifsicle, libwebp, libavif, libjxl und SVGO (SVGO läuft in einer integrierten JavaScript-Engine, Node.js ist daher nicht nötig).
- Integration in den Datei-Explorer. Wenn Sie mehrere Dateien gleichzeitig auswählen, werden sie alle in einem Fenster geöffnet.
- Nichts zu konfigurieren. Die Standardwerte sind sicher, und ein kleiner Bereich „Einstellungen“ steht bereit, falls Sie das möchten (einschließlich eines deutlich langsameren Modus für maximale Komprimierung).
- Behält standardmäßig das ursprüngliche „Änderungsdatum“ jeder Datei bei.
- Folgt automatisch dem hellen oder dunklen Modus von Windows und verwendet Ihre Farben für hohen Kontrast, wenn ein Kontrastdesign aktiv ist.
- Verfügbar auf Englisch, Französisch, Deutsch, Italienisch, Japanisch und Spanisch.

## ITALIAN

- Sette formati: AVIF, GIF, JPEG, JPEG XL, PNG, SVG e WebP.
- Usa i migliori strumenti open source sotto il cofano: oxipng, libjpeg-turbo, Gifsicle, libwebp, libavif, libjxl e SVGO (SVGO viene eseguito in un motore JavaScript integrato, quindi Node.js non serve).
- Integrazione con Esplora file. Selezionare più file insieme li apre tutti in un'unica finestra.
- Niente da configurare. Le impostazioni predefinite sono sicure e, se vuoi, c'è un piccolo pannello Impostazioni (inclusa una modalità di compressione massima, molto più lenta).
- Conserva per impostazione predefinita la data di "Ultima modifica" originale di ogni file.
- Segue automaticamente la modalità chiara o scura di Windows e usa i tuoi colori a contrasto elevato quando è attivo un tema a contrasto.
- Disponibile in inglese, francese, tedesco, italiano, giapponese e spagnolo.

## JAPANESE

- 7 つの形式: AVIF、GIF、JPEG、JPEG XL、PNG、SVG、WebP。
- 内部では最高のオープンソース ツールを使用: oxipng、libjpeg-turbo、Gifsicle、libwebp、libavif、libjxl、SVGO (SVGO は組み込みの JavaScript エンジンで動作するため、Node.js は不要です)。
- エクスプローラーとの連携。複数のファイルをまとめて選ぶと、すべて 1 つのウィンドウで開きます。
- 設定は不要です。既定値は安全で、必要なら小さな設定パネルもあります (大幅に遅くなる最大圧縮モードを含む)。
- 既定では、各ファイルの元の「更新日時」を保持します。
- Windows のライト モードまたはダーク モードに自動で合わせ、コントラスト テーマがオンのときはハイ コントラストの色を使います。
- 英語、フランス語、ドイツ語、イタリア語、日本語、スペイン語に対応しています。

## SPANISH

- Siete formatos: AVIF, GIF, JPEG, JPEG XL, PNG, SVG y WebP.
- Usa internamente las mejores herramientas de código abierto: oxipng, libjpeg-turbo, Gifsicle, libwebp, libavif, libjxl y SVGO (SVGO se ejecuta en un motor de JavaScript integrado, así que no hace falta Node.js).
- Integración con el Explorador de archivos. Al seleccionar varios archivos a la vez, se abren todos en una sola ventana.
- Nada que configurar. Los valores predeterminados son seguros y, si lo quieres, hay un pequeño panel de Configuración (incluido un modo de compresión máxima, mucho más lento).
- Conserva de forma predeterminada la "Fecha de modificación" original de cada archivo.
- Sigue automáticamente el modo claro u oscuro de Windows y usa los colores de contraste alto cuando hay un tema de contraste activado.
- Disponible en inglés, francés, alemán, italiano, japonés y español.
